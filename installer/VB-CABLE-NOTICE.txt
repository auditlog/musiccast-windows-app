# VB-CABLE — informacja producenta / vendor notice

## Polski

VB-CABLE jest produktem VB-Audio Software.
Źródło produktu: https://www.vb-cable.com/
Strona producenta: https://vb-audio.com/Cable/

VB-CABLE jest udostępniany w modelu donationware. Jeśli jest przydatny,
możesz wesprzeć jego autorów darowizną lub zakupem licencji:
https://vb-audio.com/Services/licensing.htm

Instalator zawiera standardowy pakiet VB-CABLE bez zmian w plikach producenta.
Paczki dodatkowych kabli A+B oraz C+D nie są dołączane.
W zastosowaniach profesjonalnych obowiązują warunki licencyjne producenta.

Instalacja sterownika wymaga uprawnień administratora i może wymagać restartu.
Instalator pomija wykryty sterownik. Odinstalowanie MusicCast Bridge pozostawia
VB-CABLE, ustawienia użytkownika i poświadczenia AirPlay.

Po instalacji wybierz CABLE Input jako wyjście przeglądarki/Spotify w mikserze
Windows. Nasz instalator nie zmienia domyślnego mikrofonu ani wyjścia aplikacji;
Windows może jednak wybrać nowo dodane urządzenie jako domyślne. Sprawdź je po
instalacji sterownika. Dalsze kroki znajdziesz w aplikacji pod „Tylko Yamaha…”.

Automatyczne przełączanie wyjścia Windows możesz włączyć w ustawieniach aplikacji.
Okna samego Windows i oryginalnego instalatora VB-CABLE używają języka systemu
lub producenta.

## English

VB-CABLE is an optional, separate VB-Audio Software product, not covered by
MusicCast Bridge's MIT license. Origin: https://www.vb-cable.com/
It is donationware: if useful, support its authors by donating or purchasing
a license at https://vb-audio.com/Services/licensing.htm
Professional use/deployments are subject to the vendor's licensing terms.

This installer includes the standard VB-CABLE package unchanged. Additional
cables A+B and C+D are not included. Installing a missing driver needs
administrator permission and a restart; an existing shared driver is kept.
Uninstalling MusicCast Bridge leaves VB-CABLE and your application data.

Choose CABLE Input as your browser/Spotify output in the Windows mixer, or
enable automatic Windows output switching in MusicCast Bridge Settings.
Applications with individual mixer assignments may still need to be set to
Default or CABLE Input. Set cable/player volume to 100% and adjust listening
volume on Yamaha. Driver installation may change Windows defaults; check them
after restarting.

Windows system dialogs and the original VB-CABLE installer use the system
or vendor language.
